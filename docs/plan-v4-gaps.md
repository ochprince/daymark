## 二、逐条验收标准

### 1 · 相片背景（P0）

- 相片存 **IndexedDB**，`localStorage` 只存 id —— 手机照片动辄 3–5 MB，塞进 localStorage 会直接爆配额
- 选图后**压缩**：最长边 1600px、JPEG 0.82，目标单张 < 400 KB（`createImageBitmap` + `OffscreenCanvas`，不引第三方库）
- 舞台卡把它当底图，**文字区自动加模糊遮罩**（原型：`demo.js:207` 明确写了这条），保证任何照片上都读得清
- 档案页设置里能「换一张 / 去掉」，去掉后回到纯色皮肤
- 失败兜底：浏览器不支持、压缩失败、配额满 —— 一律静默退回无照片，不挡住「记一件事」
- 验收：真机尺寸下截图能看出照片 + 文字可读；`localStorage` 里只有 id；断网可用

### 2 · 备忘 + 待办（P0）

- 倒数日详情里有「一句备忘」（单行文本，进副行展示）
- 「待办」是勾选清单：可增删、可勾选，勾完变灰但不消失
- 与提醒并列，都属于「工具」那一段，不卖萌
- 验收：写进去 → 关掉 App → 重新打开还在；舞台卡副行能看到备忘角标

### 3 · 孵化仪式（P0）

- 只在**第一件事被创建**时播一次；之后再建直接回今天页
- 流程：蛋出现 → 裂纹 → 破壳 → 小伙伴出场 → 一句欢迎 → 落到舞台卡
- `prefers-reduced-motion` 直接跳终帧；可点任意处跳过
- 播完写 `daymark.hatched.v1`，之后的版本不再播
- 验收：清空 localStorage 打开 → 播一次；第二次打开不播

### 4 · 结束本章留一句话（P1）

- 点「结束这一章」先弹一句话输入（可空，空就用默认那句）
- 写进 `Chapter.line`，藏馆翻书页里显示（该处已经能显示）
- 验收：结束 → 藏馆翻书页看到自己写的那句话

### 5 · 分享卡三模板（P1，依赖 #1）

- 贴纸：现在这个（皮肤底色 + 小伙伴）
- 相片：把这件的事的照片当底图 + 压暗 + 反白文字
- 票根：做成入场券样式（第 N 天 · 日期 · 编号）
- 切换就是在分享面板上加三个小 tab，Canvas 各画一套
- 验收：三张导出图都能打开、中文不裁、1080×1920

### 6 · 音效（P1）

- 接线位置：蓄力开始（轻微）、落定（清脆一声）、进化（一小段）、徽章盖章
- 必须遵守装扮页的「音效」开关；关掉就完全静默
- iOS 需用户手势后才能出声 —— `sfx.ts` 已经惰性创建 AudioContext，接线时别在挂载时初始化
- 验收：开关打开能听到、关掉没声音、`prefers-reduced-motion` 不静音（声音与动效是两个开关）

### 7 · 就是今天的小庆祝（P1）

- 当天进入「等待的日子」时，彩纸从顶部落下 + 小伙伴戴派对帽 + 主按钮变「说过了，明年见」
- 只在当天首次进入时播一次，同一天不重复打扰
- 验收：把某件倒数日改到今天 → 打开看到庆祝层 → 点掉后再打开不再出现

### 8 · 合上书的过场（P2）

- 归档瞬间：卡片收成一本小书 → 沿弧线飞向底部「藏馆」tab → tab 图标抖一下
- 300–450ms，可跳过；reduced-motion 直接终帧
- 验收：结束本章后能看到书飞进 tab
