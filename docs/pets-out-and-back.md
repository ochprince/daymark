# 桌宠的「出去 / 回来」：原型怎么设计的，我们缺什么

> 来源：`docs/prototype-v3/pets.js`（第 685–772 行回家、955–1080 行出场）、`pets.css`（第 374–392 行）、`proto.css`（第 510–521 行）。
> 写这份是因为我们现在的实现只抄了「会走会掉」，把最关键的一层漏了。

---

## 一、原型的设计意图，一句话

**人走了，家还在。**

卡片里的那只和桌上的那只是**同一只**。它走出卡片后，卡片里那个位置**保留原尺寸的空位**，只是暂时空着、不能点；拖回卡片中央，它自己走回去，空位重新亮起来。

我们现在的做法是两套东西并存：卡片里画一只（`<Creature>`），桌面上再跑一只（`PetLayer`）。截图里能同时看到两只，这在原型里是不可能的。

---

## 二、出去（debut）：不是一个动画，是四段接力

`pets.js` 的 `debut()` 按顺序做：

1. **走向卡片深处**：从卡片里角色的实际位置起，朝卡片中心走，**边走近边变小**（`startS` 由实测宽度算出，钳在 0.72–1.05 之间）
2. **踏上小台阶**：走到卡片顶部往下 56px 的位置顿一下（`stepY = cardTop + 56`）
3. **从画面中间跳下来**：起跳点是卡片中心，落点交给物理层（`handoffFall(x, y, vx, vy)`）
4. **交接**：`S.petOut = true`，桌宠显示、卡片那侧进入 `pet-away`

期间有两条保护：
- `debutTok` 令牌：任何时候用户关掉桌宠、或者重播，旧动画立刻作废（`abortDebut` 里 `debutTok++`）
- **减少动效时直接跳过整段**（`skipDebut()`），不做「走进去→台阶→跳下」，直接切状态

## 三、出去之后，原位置怎么处理（这是最容易漏的一点）

`pets.css` 第 376–392 行写得很明确：

```css
/* 舞台萌宠 → 桌宠：人走了，家还在（占位尺寸不变），只是暂时空着、不能点 */
.cr-wrap.pet-away,
.cr-wrap.pet-out {
  pointer-events: none;
  cursor: default;
}
.cr-wrap.pet-away .cr,
.cr-wrap.pet-home-hot ... {
  visibility: hidden;
  opacity: 0;
  pointer-events: none;
}
```

三个要点：
1. **占位尺寸不变**——`.cr-wrap` 本身不动（原型里固定 176×176），只是里面的 `.cr` 隐藏。这样卡片高度不会塌，回来时不用重排。
2. **不可点**——`pointer-events: none`，避免点到一个看不见的宠物。
3. **卡片渲染时判断**：`core.js` 第 577 行 `class="cr-wrap … ${out ? 'pet-out' : ''}"`，`out` 为真时才加类；`data-cr` 属性也只在没出去时才挂。

## 四、回来（goHome）：拖到卡片中央松手

1. **回家区域**（`homeZone`）：取 `.stage-card .cr-wrap` 的矩形，换算到舞台坐标系，`feetY = top + 高度 × 0.78`
2. **防误触**：判定区域往里收——横向各收 18%、纵向各收 16%（`mx`、`my`）
3. **悬停反馈**：拖到区域内时给 `.cr-wrap` 加 `pet-home-hot`（卡片里那块空位亮起来，告诉用户「放这儿」）
4. **松手**：进 `homing` 状态，**420ms、`1-(1-u)³` 缓出**，位置插值到卡片中心，同时 `opacity = 1 - u*0.85`（越靠近卡片越淡，像钻回去）
5. **收尾**（`finishHome`）：
   - 冒 4 颗爱心
   - `S.petOut = false`、`st.debuted = false`，精灵隐藏，**重新渲染卡片**（这样 `.pet-out` 被去掉，卡片里的宠物重新出现）
   - 卡片那侧播一次 `jump`（`void wrap.offsetWidth` 强制重排后再加类，否则同样的类不会重播动画）
   - 气泡文案改成「我回来了。」并重播 `pop`
   - 播 `pop` 音效

---

## 五、还有一条：它是怎么「自己」出去的

`pets-N6` 场景注释写得很清楚：**连续快速戳卡片里的宠物五下**（每下间隔 < 0.9 秒）→ 它兴奋乱蹦、喊一声「不行了，我要出去玩！」→ 自己走出去变成桌宠。

**慢慢摸不会触发**——所以平时「摸一下、聊一句」的节奏不受影响。这是刻意的：不打断日常互动，只在用户明显在闹它时才闹回去。

另外关掉桌宠开关时，它会**回到卡片原位**（`petOut = false` 后重渲染），不是凭空消失。

## 六、我们缺的清单

- [ ] 卡片里的宠物包成 `.cr-wrap`，桌宠在外时加 `.pet-away`（隐藏但占位、不可点）
- [ ] 卡片不再和桌宠同时显示两只
- [ ] 出场四段接力（走进去 → 台阶 → 跳下 → 交接），带 `debutTok` 作废保护
- [ ] 减少动效走 `skipDebut` 直切
- [ ] 回家区域 + 18%/16% 内缩防误触 + `pet-home-hot` 高亮
- [ ] 420ms 缓出 + 渐隐的回家动画，收尾冒爱心、卡片 `jump`、气泡「我回来了。」
- [ ] 连戳五下（<0.9s）自动出门，慢慢摸不触发
- [ ] 关掉桌宠开关 → 回卡片原位
