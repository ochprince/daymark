## 0. 怎么用这份文档

**阅读顺序（约 1 小时）**

1. 先打开原型，左栏 A→H 依次点一遍（15 分钟）。右栏会说明每一屏的设计意图。
2. 读第 1、4、5 节：知道要做什么、哪些已定。
3. 读第 6、7、8 节：这是实现时最常翻的三节（规则、数值、数据）。
4. 读第 13 节：原型里有为演示走的捷径，**不要照搬**。
5. 按第 14 节领任务。

**术语**

| 术语 | 含义 |
| --- | --- |
| 一件事（item） | 用户记录的任一条目。三类：**坚持**（正数日，现 `DayEvent`）、**习惯**（打卡，现 `CheckInEvent`）、**等待的日子**（倒数日，现 `CountdownEvent`） |
| 小伙伴 | 每件事对应的养成角色。物种见第 9 节 |
| 形态（stage） | 小伙伴的成长阶段 0–4，门槛 0/3/7/30/100 天 |
| 成长天数（growth） | 决定形态的数值，**累计、不清零**（见 6.3） |
| 休息 / 睡着 | 习惯类一段时间没记时的状态，**不是断签**（见 6.4） |
| 章节（chapter） | 一轮坚持。重置 / 结束 / 去旅行时归档 |
| 焦点舞台 | 「今天」页上唯一被放大的那件事 |
| 藏馆 | 章节书架 + 图鉴 + 徽章 + 小纸条 |
| 风格包（skin pack） | 一份完整的视觉令牌：色彩、圆角、描边、字体、投影、纹理、角色处理、动效曲线 |
| 去旅行 | v2 里「删除」的说法与流程 |

## 1. 背景与目标

**产品定位**（来自产品方向）：中性的、有亲和力的自律打卡与记事提醒工具。用**反馈型**游戏化（成长、收集、惊喜、仪式）做情绪价值；**不做**压力型游戏化（体力、连续惩罚、排行榜、限时）。

**v2 要达成的四件事**

| # | 方向 | v2 的落点 |
| --- | --- | --- |
| ① | 游戏化 · 情绪价值（总纲） | 小伙伴养成、进化过场、章节与藏馆、徽章/图鉴/纸条、告别仪式、分享卡片、相片背景 |
| ② | 中性萌系 · 亲和力 | 贴纸感角色与 UI、圆胖数字、中性配色（非粉色主导）、具体温和的文案 |
| ③ | 多套风格包 · 可自定义 | 「一套皮肤 = 一份令牌」；首发软糖，另有纸本 / 夜航 / 像素；画廊横滑预览、松手应用 |
| ④ | 注意力聚焦 | 舞台上一次只放大一件，可随时切换；数据不变 |

**约束（沿用项目既有原则，定）**：纯前端、零后端、数据不出本机、无账号、无埋点；PWA；字体自托管（不走 Google CDN）；运行时依赖保持精简。

**项目里已有的真机教训（务必继承）**

- 特效做多了在中低端机掉帧，曾整体回滚（commit `096ae81`「恢复轻量渲染」）→ 日常打卡动效节点封顶 3 个。
- 蓄力时长从 2 秒调到 0.5 秒（`d7941e9`）→ 以 500ms 为准。
- 卡片上的横滑统一给翻页、删除收进弹层（`5268682`、`3653dc6`）→ v2 舞台横滑 = 切换焦点，不放删除手势。
- 蓄力动画交给 CSS transition，JS 只在「按下」「蓄满」各跑一次，不逐帧 setState（见 `CheckInCard.tsx` 注释）。

一句话：**工具骨架完整、手感已调过，但它是三张列表 + 一次性的特效**，情绪价值停在「按下那一刻」。

## 3. 与产品方向的差距

| 方向条目 | 现状 | 差距 → v2 的做法 |
| --- | --- | --- |
| ① 核心循环 | 按下 → 蓄满 → +1 → 特效 → 结束 | 没有「回头看的理由」→ 小伙伴会长大、会说话、会睡着；打开 App 时补播错过的进化 |
| ① 养成角色 | 无 | → 4 物种 × 5 形态 + 倒数日信使 |
| ① 章节与图鉴 | `history` 以胶囊 + 列表呈现 | → 书架（一章一本书）、书页、图鉴 |
| ① 收集 / 惊喜 / 过场 | 次数里程碑亮点、节日音效 | → 徽章、图鉴、小纸条、节日彩蛋、进化过场、年度回顾占位 |
| ① 语言与被看见 | 文案工整 | → 节点句库：第 1/7/30/100 天、休息后回来、章节结束 |
| ① 结束的仪式 | 重置 / 删除 = Toast | → 告别仪式；删除 = 去旅行 |
| ① 可分享产物 | 无 | → 分享卡片（贴纸 / 相片 / 票根） |
| ① 相片背景 | 无 | → IndexedDB + 压缩 + 遮罩 + 局部模糊 |
| ② 中性萌系 | Inter + 渐变数字的克制工具风 | → 软糖风格包 + 角色 + 文案语气 |
| ③ 风格包 | 深浅两套 + 强调色；CSS 变量是雏形 | → 令牌化、一包一文件、画廊 |
| ④ 注意力聚焦 | 三页列表平级 | → 焦点舞台 + 切换面板 |

## 5. 信息架构与页面清单

### 5.1 结构

```

├── 今天（焦点舞台）
│   ├── 右上：头像堆「N 件」→ 切换面板（sheet）
│   ├── 右上：「+」→ 新建流程（sheet，3 步）→ 孵化（全屏）

│   │   │   └── 过去的章节 → 章节书页（modal）
│   │   └── 分享 → 分享卡片（全屏）
│   └── 底部圆点（当前是第几件）
├── 藏馆：章节（书架）/ 图鉴 / 徽章 / 纸条，顶部年度回顾占位
```

## 6. 业务规则

### 6.1 统一视图模型

展示层把三类事转成同一个视图对象，舞台、切换面板、档案页、分享卡片都只读它：

```ts
type ItemKind = 'since' | 'habit' | 'countdown'
type ItemView = {
  key: string            // `${kind}:${id}`，焦点与收集记录都用它
  kind: ItemKind
  title: string
  color: number          // 0–7
  species: Species | 'post'
  stage: 0 | 1 | 2 | 3 | 4   // 倒数日固定 0
  growth: number
  mood: 'idle' | 'happy' | 'sleep' | 'wow'
  // 以下按 kind 取用：大数字、单位、副行、主操作……
}
```

### 6.2 天数口径（定，沿用）

- 坚持类天数 = `daysSince(anchorOf(event), now)`：满 24 小时才 +1；手选的历史起始日锚点为当天 00:00。
- 倒数日 = `daysUntil(nextOccurrence(...), now)`：今天 = 0。
- 打卡按本地日期分桶；周从周一开始（`weekStart`）。

### 6.3 成长与形态

| 类型 | 成长天数 growth |
| --- | --- |
| 坚持 | Σ `history[].days` + 当前这一章的天数 |
| 习惯 | 有记录的**天数**累计（同一天记多次只算 1）；每周 / 每月型同样按天累计 |
| 倒数日 | 不成长 |

- 形态门槛（定）：`stageOf(g) = g≥100 ? 4 : g≥30 ? 3 : g≥7 ? 2 : g≥3 ? 1 : 0`。
- **永不退化（定）**：展示形态 = `max(stageOf(growth), peakStage)`。`peakStage` 持久化（见 8.2）。原因：坚持类的历史章节可以被删除、习惯可以撤销，growth 可能变小，但形态不能倒退。
- **习惯的 growth 必须单独存一个计数器（定）**：`days` 只保留最近 240 个周期，按天推算会在长期用户身上丢数。规则：某天的记录从 0 变 1 时 `growthDays + 1`；撤销使该天从 1 变 0 时 `growthDays − 1`。迁移时按现有 `days` 中次数 > 0 的键数初始化。
- 成长条显示「成长 g 天 · 再 n 天 → 下一形态名」；已到形态 4 显示「已经是最好的样子啦」；睡着时显示「暂停生长 · 等你回来」，进度条变灰。

### 6.4 休息（睡着）

| 周期 | 判定（今天还没记，且最近一次记录距今） | 来源 |
| --- | --- | --- |
| 每天 | ≥ 3 天 | 原型 |
| 每周 | ≥ 5 天 | 原型 |
| 每月 | ≥ 20 天 | 原型未覆盖，默认值 |

- 新建后从未记录：从创建时刻起算同样阈值。
- 睡着的表现：闭眼 + 漂浮的 z、呼吸动画；气泡「它睡着了，等你回来。不急。」；按钮文案「按住 · 叫醒它」。
- 叫醒（睡着时记一次）：气泡「你回来啦！它没有变小，只是睡了一会儿。」；首次叫醒解锁徽章「回来了」。
- 坚持类和倒数日没有休息态。

### 6.5 习惯的记录与目标

- 新字段 `target`：每个周期的目标次数。
  - `target = 1` 且每天：记一次后按钮变「今天已记 · 明天见」，再按只提示「今天已经记过啦，明天见」。
  - `target > 1`（如喝水 8 杯）：每次 +1，显示「今天 n / 8 杯」和杯子行；超过目标仍可记（「比计划还多，厉害」）。
  - 每周 / 每月：显示「本周 n / 3 次」，达标后仍可记。
  - **老数据 `target` 为空 = 不设上限**，行为与现在一致（显示「今天 n 次」，不锁定）。
- 每次记录写 `days` 和 `times`（沿用 `tapCheckIn`），可撤销（Toast 8 秒，沿用 `untapCheckIn`），撤销同步回退 `growthDays`（见 6.3）。

### 6.6 章节

| 类型 | 一章从哪到哪 | 结束方式 | 结束后 |
| --- | --- | --- | --- |
| 坚持 | 当前锚点 → 结束那一刻 | 档案页「结束这一章」（= 现在的「设为今天」重置） | 写入 `history`（`days`、`endedAt`，新增 `line`、`stage`）；锚点设为此刻；章节号 +1；**小伙伴形态不变** |
| 习惯 | `chapterStartedAt` → 结束那一刻 | 同上 | 写入新增的 `chapters[]`（天数 = 本章有记录的天数）；`chapterStartedAt` 设为此刻；**不清空 `days`/`times`，growth 不变** |
| 倒数日 | 每一次「发生」 | 当天点「说过了」 | 写入新增的 `history[]`（发生日期、留言）；该次发生加入 `ackedFor` |

- 章节号 = 已归档章节数 + 1。
- 结束仪式里的「留一句话」可空，空时存默认句「这一章写完了。」。
- 过去的章节在档案页列出，也出现在藏馆书架。章节可在书页里删除（沿用现有 `handleDeleteStreak` 的按下标删除 + 撤销）。

### 6.7 等待的日子（倒数日）

- 下一次发生**沿用 `nextOccurrence()`**，节日沿用 `festivalId` 规则。**不要照搬原型「说过了 → 日期 +365」的写法**（见第 13 节）。
- 当天（`days = 0`）：舞台进入当天态（数字换成「就是今天」、彩纸、信使戴派对帽、节点句）；主操作「说过了，明年见」→ 记入 `ackedFor` 与 `history`，当天态结束；重复型自动显示下一次。解锁徽章「生日快乐」（第一次陪一个倒数日走到那天）。
- 不重复且已过去（`days < 0`）：显示「已经过去 N 天」+ 主操作「收进藏馆」（走去旅行流程的归档，不弹仪式全屏）。原型未覆盖，按此默认。
- 信使道具：> 7 天拿信，≤ 7 天抱礼物，当天派对帽。
- 新增字段：`remind`、`memo`（一句备忘）、`todo[]`（待办，可勾选）。

### 6.8 收集

**图鉴**：键 `${species}:${stage}`。任一件事到达某形态即解锁，永不回锁。共 23 格 = 4 物种 × 5 形态 + 特别篇 3 格（信使：拥有任一倒数日即解锁；南瓜帽：万圣节当天打开；雪团：冬至当天打开，隐藏）。

**徽章**（解锁即弹窗；迁移时静默补发，不弹）：

| id | 名称 | 条件 | 隐藏 |
| --- | --- | --- | --- |
| first | 第一步 | 创建第一件事 | |
| d7 / d30 / d100 / d365 | 一整周 / 三十天 / 一百天 / 一年 | 任一件事 growth 达到 7 / 30 / 100 / 365 | |
| back | 回来了 | 第一次叫醒睡着的小伙伴 | |
| night | 夜猫子 | 在 0:00–4:59 记过一次 | |
| early | 早起鸟 | 在 5:00–5:59 记过一次 | |
| chapter | 翻篇 | 第一次结束一章 | |
| bday | 生日快乐 | 第一次在倒数日当天点「说过了」 | |
| share | 晒一晒 | 第一次保存或分享卡片 | |

**小纸条**：见 6.9。**年度回顾**：v2 只做占位卡「12 月 31 日开启」+ 剩余天数，内容不在 v2 范围。

### 6.9 惊喜（低频、不可预测）

- **小纸条**：App 进入前台时判定——距上次纸条 ≥ 3 天，且随机命中 30%，且本自然周已出 < 2 张 → 舞台上的小伙伴手里出现一张折起的纸条（小图标 + 轻微晃动），**用户点了才展开**；不自动弹窗。
  - 原型里是直接弹出（演示用），正式版按此入口实现。
  - 纸条内容从文案库随机抽，不重复，抽完再循环；签名是当前焦点小伙伴的名字。
- **节日彩蛋**：只在节日当天生效。万圣节（10/31）：所有小伙伴戴南瓜帽、舞台出现蝙蝠、问候「万圣节快乐 🎃」、当天第一张纸条为节日句。圣诞、春节等进排期表（P3），春节用农历离线表。
- **摸摸它**：轻点小伙伴 → 跳一下 + 飘爱心 + 换一句（`TAP_LINES`）；当天第 7 次点击固定出「今天第 7 次摸我了……有点害羞。」。

### 6.10 焦点

- 聚焦的是**展示**，不是数据。焦点存 `daymark.focus.v1`（存 `ItemView.key`）；下次打开仍是它；它被删除时焦点移到同组下一件，没有则上一件，再没有则显示空态。
- 新建完成后，新的那件成为焦点。
- 切换顺序（舞台横滑与底部圆点共用）= 切换面板的顺序：先坚持（按 `sortEvents`），再习惯（按 `sortCheckIns`），再等待的日子（按最近发生）。**原型的圆点用的是数组顺序，正式版以此为准。**
- 「今天还没记」只用柔和黄点，不改变排序、不出红点或未读数。

### 6.11 打开 App 时的「回头看」

进入前台时依次检查，同一时刻只出一个全屏层：

1. 有件事的展示形态 > 已看过的形态（`seenStage`）→ 播放进化过场（多件时只播一件，其余合并成 Toast「还有 2 只也长大了」，在档案页可以看到）。
2. 有倒数日今天发生 → 焦点切过去（只在当天第一次打开时）。
3. 小纸条判定（6.9）。

```ts
/** 一章：兼容现有 Streak（只有 days/endedAt 的老数据照常可读） */
export type Chapter = Streak & {
  line?: string          // 结束时留的一句话
  stage?: 0|1|2|3|4      // 结束时的形态（书页拍立得用）

  | { kind: 'none' }

export type DayEvent = {

  species?: Species

}

export type CheckInEvent = {
  /* 现有字段不变 */
  species?: Species
  target?: number | null       // 每周期目标次数；空 = 不设上限

  chapterStartedAt?: number    // 当前章起点；空 = createdAt
  chapters?: Chapter[]

}

export type CountdownEvent = {

  memo?: string
  todo?: { text: string; done: boolean }[]
```

### 8.4 相片

- 上传 → `createImageBitmap` → Canvas 缩放到长边 1600px → `toBlob('image/webp', 0.82)`（不支持 WebP 时用 JPEG 0.85）→ 存 IndexedDB → 事件上只存 `photoId`。
- 可读性：舞台上半张清晰；文字区域叠「底部 50% 渐变遮罩 + `backdrop-filter: blur(14px)`」；小伙伴气泡改为不透明白底。见原型 H1 与 `proto.css` 的 `.photo` / `.photo-blur` / `.has-photo`。
- IndexedDB 不可用（隐私模式等）：隐藏相片入口，其余功能不受影响。去旅行 / 删除时连带删图（撤销期内保留）。

## 9. 小伙伴（角色资产）规格

| 物种 id | 名字 | 默认用于 | 形态 0 / 1 / 2 / 3 / 4（0 / 3 / 7 / 30 / 100 天） |
| --- | --- | --- | --- |
| sprout | 芽芽 | 坚持类；其他兜底 | 壳宝宝 · 冒芽 · 双叶 · 开花 · 花冠 |
| moon | 眠眠 | 早睡、冥想等夜晚类 | 壳宝宝 · 月牙 · 睡帽 · 星星帽 · 星夜 |
| drop | 咕噜 | 一天多次（喝水） | 壳宝宝 · 小水珠 · 浪花 · 泡泡 · 彩虹 |
| star | 跑跑 | 运动、每周几次 | 壳宝宝 · 星芽 · 星耳 · 汗带 · 金冠 |
| post | 信信 | 倒数日（不长大） | 道具：信 / 礼物 / 派对帽 |

- **结构**：`viewBox 0 0 200 200`；身体（圆团 / 水滴 / 蛋）+ 背层（耳朵、彩虹、手脚）+ 表情 + 头饰。形态越高体型越大（缩放 0.74 → 1.0，以脚底为原点）；形态 2 起有脚，3 起有手。
- **表情**：idle（睁眼、小嘴）/ happy（^^ + 张嘴）/ sleep（闭眼 + 小 o 嘴）/ wow（大眼 + O 嘴，用于孵化与进化）。
- **颜色全部走 CSS 变量**：`--c`（主色）、`--c2`（深一档）、`--cr-line`、`--cr-lw`，以及 `--leaf --petal --pistil --spark --shell --gold --band --foam --bubble --rb1~3 --mouth --blush --gift --paper`。换风格包不重画。
- **剪影**（图鉴未解锁、档案页未到的形态）：所有填充与描边换成 `--sil`，隐藏脸和高光。
- **叠加层**：节日帽（南瓜）替换头饰；以后的节日装扮同样做叠加层。
- **移植**：把 `docs/prototype-v2/creatures.js` 的 `creature()` / `badge()` 改写成 `src/components/Creature.tsx`、`Badge.tsx`（输入 props、输出 SVG）。clipPath id 需改用 React `useId()`，避免同屏多只时冲突。
- **美术**：原型是工程师手写的 SVG，可直接上线作 v2 版本；若有插画师介入，需保持上述分层与变量约定。

### 10.3 实现约定

- 一包一文件：`src/skins/jelly.css` 等，只含 `[data-skin=jelly] { … }`；根节点挂 `data-skin`、`data-accent`、`data-num`、`data-texture`。
- 自定义只覆盖当前包，画廊缩略图不受影响（用 `.phone[data-num=…]` 这种限定在 App 根节点的选择器，见原型）。
- 现有变量映射：`--surface`→`--surface`，`--text/-2/-3`→`--ink/2/3`，`--line`→`--hair`，`--radius-card`→`--r2`，`--ease-spring`→`--ease-pop`，`--shadow-card`→`--soft`。迁移期可以让旧名指向新名，逐步替换。
- **不允许组件里出现 `if (skin === …)`**：所有差异都要能用令牌或包内补丁表达。
- 字体：`@fontsource/baloo-2`、`@fontsource/instrument-serif`、`@fontsource/silkscreen`、`@fontsource/caveat`；中文萌系字（ZCOOL KuaiLe）只用于进化/孵化/仪式标题与纸条，按用到的字子集化或换成 SVG 文字。数字字体按包懒加载。
- 对比度：正文 ≥ 4.5:1、大数字 ≥ 3:1，四套包都要过（纸本与像素的 `--ink3` 需要复核）。

## 11. 文案规范与文案库

**原则（定）**

- 小伙伴说的话：具体、非功能性、不催促。好的例子：「今晚早点睡吧，眠眠已经在打哈欠了」「第 3 杯，咕嘟咕嘟。还差 5 杯也没关系」。
- 工具信息（日期、提醒、次数）放在副行，保持清晰，不卖萌。
- **禁用**：断签、失败、警告、落后、再不…就…；红色、红点、未读数、倒计时施压。

**节点句（已在原型里，正式版抽成 `src/lib/lines.ts`）**

| 场景 | 句子 | 原型位置 |
| --- | --- | --- |
| 坚持 第 0 / 1–6 / 7 / 8–29 / 30 / 31–99 / 100 / 100+ / 365+ 天 | 「从这一刻开始算。今天也可以什么都不做。」「开始了。不用急，它也才刚醒。」「一整周了。你比自己以为的更能坚持。」「过了一周，叶子长得比上周精神。」「三十天，足够让一件事变成你的一部分。」「一个多月了，它已经习惯有你陪着。」「一百天。谢谢你，没有放下它。」「第 N 天。这已经不是坚持，是你本来的样子。」「一年多了。谢谢你一直把它放在心上。」 | `core.js` `lineFor()` |
| 习惯 未记 / 记后 / 多次 / 达标 / 超标 / 每周 | 「今天还没来找它。按住它，记一下就好。」「记下了。今天剩下的时间，都是你的。」「第 n 杯，咕嘟咕嘟。还差 m 杯也没关系。」「今天喝够啦！咕噜圆滚滚的。」「比计划还多，厉害。」「本周第 n 次，跑得真好。」「这周的目标完成啦！剩下的随意。」 | `lineFor()`、`afterLogLine()` |
| 睡着 / 叫醒 | 「它睡着了，等你回来。不急。」「你回来啦！它没有变小，只是睡了一会儿。」 | `lineFor()`、`completeLog()` |
| 倒数 >7 / ≤7 / ≤3 / 当天 | 「还有 N 天。现在开始想礼物，刚刚好。」「还有一周，刚好来得及慢慢准备。」「只剩 N 天了，东西都准备好了吗？」「就是今天！记得说一声生日快乐。」 | `lineFor()` |
| 进化 3 / 7 / 30 / 100 | 「三天了，它冒出了一点点新东西。」「一整周。你和它都长出了新的样子。」「三十天，足够让一件事变成你的一部分。」「一百天。谢谢你，没有放下它。」 | `overlays.js` |
| 章节结束 / 去旅行 | 「这一章会被好好收进藏馆。X 不会变小，下一章从今天重新数。」「谢谢你们一起走过的 N 天。它会把这些日子装进行李，藏馆里留着你们的合照。」 | `overlays.js` farewell |
| 摸摸它 | `TAP_LINES`（7 句）+ 第 7 次彩蛋句 | `core.js` |

## 12. 动效、性能与无障碍

**动效预算（定）**

| 层级 | 时机 | 预算 |
| --- | --- | --- |
| 常驻 | 小伙伴呼吸 / 漂浮 | 只用 CSS transform 动画；舞台外（列表、图鉴）不跑循环动画 |
| 日常 | 每次记录 | ≤ 3 个节点（见第 7 节）；粒子 ≤ 22 个，1s 内全部移除 |
| 低频 | 进化、孵化、章节结束、节日当天 | 1.5–2.5s 过场，随时可跳过 |
| 稀有 | 小纸条、隐藏徽章 | 频率上限见 6.9 |

**性能验收**：中低端 Android（参考 2021 年千元机）+ iPhone 12 级别，日常记录全程 ≥ 55fps；进化过场不掉到 45fps 以下；舞台首屏渲染 < 100ms（不含字体）。

**无障碍**：所有可点元素有可读名称（原型只给了少数 `aria-label`，正式版需补全，尤其是图标按钮、头像堆、圆点）；按住记一次需提供替代（读屏时长按 = 双击后再双击确认，或档案页里提供「记一次」按钮）；图标按钮触控区 ≥ 44×44；减弱动效见第 7 节；颜色不是唯一信息载体（睡着同时有文字）。

## 13. 原型说明：能照搬什么、不能照搬什么

**原型是什么**：纯 HTML/CSS/JS（无构建），一个全局对象 `window.DM` 串起五个模块，`innerHTML` 整块重绘。它的目的是验证体验与视觉，**不是代码基线**。

| 可以直接拿来用 | 说明 |
| --- | --- |
| 视觉与布局 | 尺寸、间距、圆角、层级以原型为准（`proto.css`、`overlays.css`、`tabs.css`） |
| 令牌 | 四套包的值（`proto.css` 顶部） |
| 角色与徽章 SVG | `creatures.js`，按第 9 节移植 |
| 文案 | 第 11 节表格 |
| 规则函数的思路 | `stageOf`、`growthOf`、`sleeping`、`lineFor`、`afterLogLine`、`endChapter`（`core.js`），移植时按第 6 节修正 |

| **不要照搬** | 正式做法 |
| --- | --- |
| 蓄力 600ms | 500ms（D8） |
| 日期用「相对今天的天数偏移」+ 演示用 `simDay` | 用真实时间戳与 `days.ts` 现有函数 |
| 倒数日「说过了」把日期改成 +365 天 | 沿用 `nextOccurrence()`，记 `ackedFor`（6.7） |
| 习惯 growth 直接存在内存对象上 | 持久化 `growthDays`，撤销要回退（6.3） |
| 形态直接由 growth 算出 | 取 `max(stageOf, peakStage)`（6.3） |
| 小纸条直接弹出 | 小伙伴手里出现纸条，点了才开（6.9） |
| 舞台圆点按数组顺序 | 按切换面板分组顺序（6.10） |
| 相片是内置的日落 SVG | 用户上传 + IndexedDB（8.4） |
| Google Fonts CDN | `@fontsource` 自托管（D13） |
| 只有 5 个颜色 | 8 个颜色索引（D9） |
| 档案页设置行只是展示 | 编辑沿用现有弹层字段，套新样式 |
| 新建「选过去的日子」固定 30 天前 | 日期选择器（沿用 `EventSheet` 的起始日期控件） |
| 左右说明栏、演示开关 | 仅演示，不进产品 |

**原型未覆盖、需按本文默认实现的**：每月周期的展示（同每周，「本月 n / 目标」）、不重复倒数日过期（6.7）、10 件以上时的切换效率（Q5）、编辑表单、完整节日面板、年度回顾内容、提醒设置细节、数据导出格式（沿用现有 JSON 结构，打包三类事 + collection + travel）。
