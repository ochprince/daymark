## 一、v3 到底改了什么

| 模块 | v2 / 我们现在的做法 | v3 重新设计 |
|---|---|---|
| 宠物 | 静态 `<Creature>` 插画，长按摸摸 | **活的桌宠**：物理引擎（重力 2200px/s²、平台扫描、拖拽抛出）、13 个状态动画、Shimeji 序列帧格式、事件响应（充能时跳上按钮、记录时撒爱心） |

| 色彩 | `color: 0..n` 索引 | **5 个色相**（mint / sky / grape / lemon / coral），每色两级 `--h-X` / `--h-X-2`，宠物 SVG 填充全靠它 |
| 系统表面 | 没有 | 小组件（3 尺寸）、灵动岛、锁屏卡片、AlarmKit 闹钟 —— 对应未来 iOS 原生工作 |
| 商业化 | $0.99 一次性买断 | **订阅制**：全功能免费，付费只加深额度。年度 ¥18（先试 7 天）/ 永久 ¥28。免费同时 20 件事、1 套默认主题、1 个小组件、1 条灵动岛；订阅把这些件数和套数放开。详见第四节 |
| 数据模型 | 事件 + checkins + 章节数组 | 事项含 `hue`、`charge`（已充能秒数）、`prev`（上一章结束日）、`chapters`，阶段 0–4 |

v3 的宠物还有一条**版权红线**（README 第 26–30 行）：Shimeji 包多为粉丝作品，App 内只随附原创「麻糬」（SVG 程序生成），用户本地导入的包永不离开设备，且不能照抄 Shimeji-ee 的 GPL 代码——只能学格式。

2. **定价按 v3 的新方案**：年度 ¥18（先试 7 天）/ 永久 ¥28 双轨。IAP 因此是「自动续期订阅组 + 非消耗型终身档」两件商品，不再是 $0.99 买断。年费和永久买的是同一份额度，不是两套功能。
   - `src/lib/entitlement.ts` 的状态从 `pro: boolean` 扩成 `'free' | 'trial' | 'year' | 'life'` 加到期日 `proUntil`。这一步代码里已经有了。
   - **权益口径改掉**（2026-11-07）：不再用付费墙关掉整块功能。免费版是完整产品，订阅只是同一功能的更多件数、更多套数。具体边界见下表。代码里现在仍是旧口径（8 件事、藏馆只翻 3 本、分享卡 / 宠物包 / 灵动岛 / 闹钟 / iCloud 整闸关闭），第 3 期按本表改，本文件先定边界。
3. **桌宠只用原创「麻糬」**：不随附任何 Shimeji 包，**首版不做本地导入**（`UIDocumentPicker` 那套以后再说），也就不存在版权与审核风险。

- 第 3 期的门禁读 `status` / `proUntil`，试用到期回到免费额度。到期不删数据、不藏已写下的内容，只拦住「再新增」。

### 免费与订阅的边界

一句话：**功能做出来就给免费用户用完。订阅买的是深度——同样的事，可以同时维护更多件、换更多套、在系统里挂更多个。** 用户没摸过的功能不会产生付费意愿，所以不存在「这是完整版才有的功能」。

三条执行规则：

1. **额度只拦新增。** 订阅到期、或免费用户本来就超过额度（比如以后把上限从别处降下来），已经存在的事、相片、章节、提醒时刻都还在，能看、能改、能记、能导出。不能做的只有：再建第 21 件事、再放第 2 个小组件、再启用另一套主题。
2. **陪伴不设额度。** 成长、进化、聚焦切换、藏馆、章节、图鉴、徽章、纸条、节日彩蛋是这个产品本身，不拿来卖。旧口径里「免费只能翻最近 3 本」作废——那是在藏用户自己写下的历史。
3. **数据不能被墙扣住。** JSON 导出 / 导入永远免费。iCloud 是「换机不用自己拷文件」的更深一档，不是导出的替代品。

你定的三个数写在表里：**同时 20 件事、1 套默认主题、系统表面各 1 个。** 其余格子按同一条原则补齐，数字若要改，改格子里的数，不改「免费能用、付费更多」这条结构。

| 权益 | 免费 | 订阅（年费 / 永久相同） | 超过额度之后 |
|---|---|---|---|
| 同时在册的事 | **20 件**。坚持、习惯、倒数合计，不按种类拆开 | 不限 | 已有的都能记、改、删、导出；不能新建第 21 件。结束进藏馆的章节**不占**这 20 件 |
| 主题 | **软糖 1 套**，这一套里的主色、数字字形、纹理都能调 | 纸本、夜航、像素，以及以后新增的包 | 界面回到软糖。上次选的包记着，续费后恢复，不要求重选 |
| 跟随系统深色 | 有。深色用软糖自己的深色变量，**不算**占用夜航 | 可以改用夜航这套审美 | 夜航是另一套主题，不是「系统深色模式」本身 |
| 每件事的色相 | 5 个色相都能选 | 同左 | 色相是用来分辨这件事的，不是主题包 |
| 小伙伴物种 | 芽芽 / 眠眠 / 咕噜 / 跑跑，倒数日的信信 | 同左 | 选物种是新建一件事的一部分 |
| 桌宠 | 焦点那一只：物理、拖拽、说话、对记录和充能的反应，都在 | 同左。首版只有麻糬 | 以后若做原创宠物包：免费留麻糬，订阅再加包。包没做出来之前，这一行没有付费差 |
| 桌面小组件 | **1 个**。小 / 中 / 大任选一种，三种事项都能绑，习惯类可以在组件上直接 +1 | 可以再放多个，尺寸也能混用 | 多出来的停在最后一次的内容上，不再刷新。用户改选「留下哪一个」，不删掉配置 |
| 灵动岛与锁屏 | **1 条**实时活动。灵动岛和锁屏卡是同一条活动的两种样子，算 1 个，不各算各的 | 可以同时挂更多件事。顶到系统允许的条数为止，App 不再另加一道墙 | 只留当前焦点那一条 |
| 本地通知 | 每件事都能设每天 / 每周 / 提前几天 | 同左 | 提醒是这个工具的本职，不拿件数卖 |
| 闹钟式提醒 | **1 件事**可以走 AlarmKit 全屏闹钟 | 不限件数 | 多出来的退回普通本地通知，提醒时刻留着 |
| 相片背景 | 同时 **3 张** | 不限 | 已贴上的照常显示；去掉一张才能再贴一张 |
| 分享卡 | 默认贴纸模板，次数不限，不加水印 | 另加相片、票根两套模板 | 传播不要限额。付费差是卡面，不是「能不能分享」 |
| 备忘与待办 | 可用。单条待办仍最多 50 条，那是输入上限，不是付费墙 | 同左 | — |
| 藏馆 / 章节 / 图鉴 / 徽章 / 纸条 / 节日 | 全部可读、可解锁 | 同左 | 不设本数 |
| 导出 / 导入 | JSON 备份可用 | 同左，另加 iCloud 自动同步 | 到期后停止同步，这台设备上的数据还在 |
| 音效、触感、减弱动效、语言 | 可用 | 同左 | — |

小组件和灵动岛**各给 1 个，不是二选一**。两种表面是两种用法，只放行一种，另一种就仍然是关掉的，用户不会为没见过的东西付钱。若要改成「系统表面总共只能放 1 个」，把这两行收成一个共享名额即可，表的其余部分不用动。
