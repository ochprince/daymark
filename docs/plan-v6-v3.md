## 一、v3 到底改了什么

| 模块 | v2 / 我们现在的做法 | v3 重新设计 |
|---|---|---|
| 宠物 | 静态 `<Creature>` 插画，长按摸摸 | **活的桌宠**：物理引擎（重力 2200px/s²、平台扫描、拖拽抛出）、13 个状态动画、Shimeji 序列帧格式、事件响应（充能时跳上按钮、记录时撒爱心） |
| 页面结构 | 今天 / 藏馆 / 装扮 | 今天 / **箱子** / **时间线** |
| 提示信息 | toast + 气泡 | 宠物说话气泡（自适应方向、避开状态栏与边缘）+ 场景注释体系 |
| 色彩 | `color: 0..n` 索引 | **5 个色相**（mint / sky / grape / lemon / coral），每色两级 `--h-X` / `--h-X-2`，宠物 SVG 填充全靠它 |
| 系统表面 | 没有 | 小组件（3 尺寸）、灵动岛、锁屏卡片、AlarmKit 闹钟 —— 对应未来 iOS 原生工作 |
| 商业化 | $0.99 一次性买断 | **订阅制**：免费核心（同时 8 件事）+ 年度 ¥18（先试 7 天）/ 永久 ¥28；Pro 解锁情绪层、宠物包、锁屏与灵动岛、闹钟、iCloud 同步、不限件数 |
| 数据模型 | 事件 + checkins + 章节数组 | 事项含 `hue`、`charge`（已充能秒数）、`prev`（上一章结束日）、`chapters`，阶段 0–4 |

v3 的宠物还有一条**版权红线**（README 第 26–30 行）：Shimeji 包多为粉丝作品，App 内只随附原创「麻糬」（SVG 程序生成），用户本地导入的包永不离开设备，且不能照抄 Shimeji-ee 的 GPL 代码——只能学格式。

## 二、分期与依赖

### 第 1 期：地基（可并行，互不冲突）

- [ ] **A · 色彩与数据模型**：引入 5 色相系统、`charge`/`prev`/`chapters` 字段、旧数据迁移（`color: 0..n` → `hue`），纯 `src/lib` 层 + 单测
- [ ] **B · 宠物资产层**：把 `creatures.js` 的四系物种 × 阶段造型 + 十三个状态动画移植成 React 组件（SVG 程序生成，无外部资源）
- [ ] **C · 桌宠物理层**：`PetLayer`（全屏覆盖、`pointer-events: none` 除精灵本身）、平台扫描、重力/行走/坐/睡/掉落/攀爬、拖拽与抛出、说话气泡（避让状态栏与屏幕边缘）
- [ ] **D · 系统表面（Web 模拟）**：小组件三尺寸、灵动岛、锁屏卡、闹钟卡的界面与状态机，做成独立组件 + 独立演示入口，等 Xcode 到位再接原生

### 第 2 期：结构改造（依赖 A）

- [ ] 标签页改成 今天 / 箱子 / 时间线；现有「藏馆」内容并入箱子
- [ ] 宠物事件总线接到真实动作：记录 → 撒爱心、充能 → 跳上计时按钮、点宠物 → 撒娇

### 第 3 期：商业化（需先拍板定价，见第四节）

- [ ] `DM.pro.gate()` 式的统一门禁（pets / sync / widget）
- [ ] 试用 7 天 → 年度 / 永久 两种状态机
- [ ] 宠物包商城 + 本地导入

### 第 4 期：iOS 原生（需要 Mac / Xcode，当前环境只能准备代码与文档）

- [ ] WidgetKit 三尺寸小组件（App Group 读数据）
- [ ] ActivityKit 灵动岛与锁屏实时活动
- [ ] AlarmKit 闹钟提醒（要审批「关键提醒」权限）
- [ ] 文件导入桌宠包（`UIDocumentPickerViewController` + 本地存储）

## 四、三条已拍板（2026-11-03，以此为准）

1. **页面结构沿用「今天 / 藏馆 / 装扮」**——不引入 v3 的「箱子 / 时间线」。v3 里箱子的内容（图鉴、皮肤、备份）继续留在现有藏馆与装扮页，只是按 v3 的视觉与色彩重排。
2. **定价按 v3 的新方案**：年度 ¥18（先试 7 天）/ 永久 ¥28 双轨。IAP 因此是「自动续期订阅组 + 非消耗型终身档」两件商品，不再是 $0.99 买断。
   - 这意味着 `src/lib/entitlement.ts` 的状态要从 `pro: boolean` 扩成 `null | 'trial' | 'year' | 'life'` 加到期日 `proUntil`。
3. **桌宠只用原创「麻糬」**：不随附任何 Shimeji 包，**首版不做本地导入**（`UIDocumentPicker` 那套以后再说），也就不存在版权与审核风险。

对应调整：
- 第 2 期原来写的「标签页改成 今天/箱子/时间线」作废，改为「在现有三页里落 v3 的视觉与色彩」。
- 第 3 期的门禁按订阅状态机改：`gate()` 读 `pro`/`proUntil`，试用到期回落免费层。
- 第 4 期去掉文件导入桌宠包一项。
