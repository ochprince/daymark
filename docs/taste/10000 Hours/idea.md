# 一万小时 · 整体产品观察

> 看的是：`4.introduce-pets.png`（陪伴宠物横滑）、`5.introduce-others.png`（首次完成引导）、`6.home.png`（主页）、`7.data-from-top-right.png`（数据统计）、`8.editor.png`（编辑项目）、`9.subscription.png`（订阅）、`10.setting.png`（设置）

## 观察要点

1. **整体视觉**：星空背景 + 卡通插画人物 + 陪伴宠物，元素统一、观感舒服。
2. **陪伴宠物**（`4.introduce-pets.png`）：横滑选择陪伴；插画精致，且会动。
3. **首次完成引导**（`5.introduce-others.png`）：在庆祝完成的同时介绍更多亮点——尤其要强调**桌面小组件**：自律/打卡类 App Store 竞品里很常见；可随时看进度、不用打开 App（这点值得我们对标实现）。
4. **功能主页**（`6.home.png`）：与我们的方向一致，**焦点落在一件事**上（当前项目卡片 + GO），而不是一屏堆很多任务。
5. **数据统计**（`7.data-from-top-right.png`）：右上角入口打开数据统计面板——我们尚未设计，但有明确价值（总时长、打卡天数、连续、日均、投入趋势热力图、按项目占比等）。
6. **编辑项目 · 陪伴增值**（`8.editor.png`）：「需要陪伴」单独一块；不需要陪伴可正常用，要更高情绪价值则付费。黑白表单 + 星空深色陪伴卡，让增值区更抢眼。
7. **订阅与商业模式**（`9.subscription.png`）：免费下载、免费使用，高级能力会员订阅；订阅页能力说明与价位档位清晰，提供 7 天免费试用，整体成熟、易接受。**无广告**——可能与我们先前「免费版靠广告区分」的设想冲突，值得重新评估。
8. **设置**（`10.setting.png`）：右上角第二按钮为设置；**价值最大的 Pro 置顶 + 黑色显眼卡片**引流。支持本机数据与 **iCloud 同步**；底部「给我们评分」「分享给朋友」等个人开发者常见的增长入口。

## 两个感受

1.  **情绪价值（陪伴、主题、白噪音等）做成可选层**：默认路径完整可用；深色/星空区块在编辑与订阅里单独呈现，对应付费而非阻断核心计时。
2. **留存靠系统能力而非打开 App**：首次里程碑用两步引导（小组件 + 提醒）；数据可 iCloud；变现以订阅试用为主，**不插广告**降低抵触。
